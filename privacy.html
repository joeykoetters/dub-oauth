Privacy Policy

Last updated: October 26, 2026

Dub is a personal assistant application used solely by its owner. It is not available to the public.

Data accessed

With the owner's consent, Dub accesses the owner's own Google account data (such as Calendar events) through Google APIs, only to perform tasks the owner requests.

Use and storage

Data is processed on the owner's own computer. Access tokens are stored locally on that computer. No data is sold, shared with third parties, or used for advertising.

Google API Services

Dub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
